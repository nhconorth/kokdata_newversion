# ระบบแสดงรายการสถานีตรวจสอบ

เว็บแอปพลิเคชันสำหรับแสดงรายการสถานีตรวจสอบคุณภาพน้ำและดิน

## การติดตั้ง

1. ติดตั้ง dependencies:
```bash
pip3 install -r requirements.txt
```

## การใช้งาน

### วิธีที่ 1: รันด้วย Python
```bash
python3 app.py
```

### วิธีที่ 2: รันด้วย Script
```bash
./run.sh
```

### เปิดเบราว์เซอร์
หลังจากรันแล้ว ให้เปิดเบราว์เซอร์และไปที่:
- `http://localhost:8080`
- หรือ `http://127.0.0.1:8080`

**หมายเหตุ:** ใช้ port 8080 แทน 5000 เพราะ port 5000 ถูกใช้โดย AirPlay บน macOS

### แก้ปัญหา Port ถูกใช้งาน
หากพบ error "Address already in use":
```bash
# หา process ที่ใช้ port 8080
lsof -ti:8080

# หรือเปลี่ยน port ใน app.py เป็น 8081 หรือ port อื่น
```

### ตรวจสอบว่าแอปพลิเคชันรันอยู่
ใน terminal ควรเห็นข้อความ:
```
🚀 กำลังเริ่มเว็บแอปพลิเคชัน...
🌐 เปิดเบราว์เซอร์ที่: http://localhost:8080
 * Running on http://0.0.0.0:8080
```

## ฟีเจอร์

- แสดงรายการสถานีทั้งหมดจากฐานข้อมูล SQLite
- ค้นหาสถานีด้วยชื่อสถานี, แม่น้ำ, หรือตำแหน่งที่ตั้ง
- กรองข้อมูลตามแม่น้ำและจังหวัด
- UI ที่สวยงามและใช้งานง่าย
- Responsive design รองรับทุกขนาดหน้าจอ

## ไฟล์ที่เกี่ยวข้อง

- `app.py` - Flask application
- `templates/index.html` - หน้าเว็บหลัก
- `kok_data.db` - ฐานข้อมูล SQLite
- `requirements.txt` - Python dependencies
